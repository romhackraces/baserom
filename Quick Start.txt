These are the short instructions for how to use this baserom:

    1. Put a copy of your clean, headered Super Mario World ROM in the
       resources folder, renamed "clean.smc"

    2. Run the provided setup script to download all the tools and 
       setup the baserom.
       
    3. Launch Callisto (found in tools/Callisto) to run a first "Build"
       of your project to make sure everything went smoothly. 

    4. After that, run "Edit" to launch Lunar Magic to edit the ROM,
       and remember to use the "Update" to apply any ASM changes.

Good luck, happy ROM hacking!

Some things to remember:

    * Don't run the provided tools separately from Callisto as it will
      overwrite their changes or cause other problems like data loss if
      or when it performs a Rebuild.

    * Editing your project with an external copy of Lunar Magic may result
      in data loss if Callisto re-inserts different levels.

    * You can easily "remove" Asar patches from your project, if they're
      omitted from Callisto's patch list (found in tools/Callisto).

    * The "Rebuild" action in Callisto should be used sparingly as it takes
      more time; if the "Update" action is insufficient Callisto will run
      a Rebuild automatically

    * There's no special extra process for adding resources to your project,
      just don't insert them directly with the tools.

If you need help don't hesitate asking questions in the Romhack Races
Discord server, or consult the detailed Readme for more information.
